# XD Maze

2〜6次元の迷路を一人称視点で歩く。ドリームコア風の見た目で、タブレットのタッチ操作に対応。

- `index.html`: 一人称版。x・y が床、z が階、w・v・u は「層」で、移ると世界の色が変わる。
- `shooter.html`: 4次元の一人称シューター。4D の目が持つ 3 次元の網膜のうち、画面に載らない 1 軸を色に畳み込んで見せる(中央の層はそのまま、ana 側は赤、kata 側は青の輪郭と影)。
- `map.html`: 盤面を並べて全体を見下ろす版。
- `core.js`: 次元に依存しない迷路生成(ランダムDFS、Wilson 法)と最短路探索(BFS)。

ビルド不要。`index.html` を開けば動く(three.js を CDN から読むのでネット接続が要る)。

操作(一人称版): 画面のボタン、横スワイプで向きを変える、タップで前進。
キーボードは 矢印/WASD = 歩く・向く、R/F = z、E/Q = w、C/Z = v、2/1 = u。

テスト: `node test.mjs`
